研究了一下数据增强
1.把原始图像统一缩放到72×72，不是最终模型输入尺寸，后续随机裁剪，模拟 “物体在画面中偏移” 的效果
2.每张图片 50% 概率左右镜像翻转，50% 保留原图，锥桶左右镜像基本不影响识别
3.将图像在 -10° ~ +10° 之间随机旋转一个小角度，模拟拍摄时轻微歪斜、物体摆放角度偏差
4.亮度：模拟环境明暗、逆光 / 强光；对比度：模拟画面深浅差异；饱和度：模拟色彩浓淡、不同拍摄设备
仅对训练集

批次大小：增大时训练快，但过拟合风险高

数据集对象：存储所有训练图片和标签
数据加载器：基于 train_set 封装而来，按 batch_size 分批读取数据、打乱顺序、迁移到显存，供训练循环迭代使用

损失函数：交叉熵损失 
预测和真实类别差距越大，损失越大、梯度越强，参数更新幅度大
预测接近正确类别，损失趋近于 0，更新变平缓

优化器：随机梯度下降算法（SGD）
lr 学习率：参数每次更新的步长
momentum 动量：累加历史梯度，越接近 1，惯性越强，震荡越小
weight_decay L2权重衰减（正则化）：在损失函数里额外增加一项权重惩罚，不让网络权重变得过大，抑制过拟合

学习率：自适应学习率调度器（从固定梯度学习率调度器优化过来）
mode="max"：指标越大越好
factor 学习率衰减系数：触发降级时，计算新学习率
patience  耐心轮数：连续 10 次监控周期内，指标都没有新高，才执行降学习率
min_lr 学习率下限：学习率最低降到xx之后不再继续衰减

每轮次计算当前轮次损失值，根据梯度更新网络权重参数，根据每轮在test1上的准确率更新学习率

如果当前测试集1准确率大于历史最优，保存覆盖当前模型至pth/model_best.pth
