动力学模型

计算前后轮侧偏角
前轮侧偏角 = 前轮转角 − (横向速度 + 质心到前轴距离 * 横摆角速度) / 纵向速度
后轮侧偏角 = −(横向速度 − 质心到后轴距离 * 横摆角速度) / 纵向速度

计算轮胎横向力
前轮横向力 = 前轮侧偏刚度 * 前轮侧偏角
后轮横向力 = 后轮侧偏刚度 * 后轮侧偏角

计算横向加速度、横摆角加速度
横向加速度 = (前轮横向力 + 后轮横向力) / 整车质量 − 纵向速度 * 横摆角速度
横摆角加速度 = (质心到前轴距离 * 前轮横向力 − 质心到后轴距离 * 后轮横向力) / 横摆转动惯量

积分更新速度状态
新横向速度 = 原横向速度 + 横向加速度 * 仿真步长
新横摆角速度 = 原横摆角速度 + 横摆角加速度 * 仿真步长

积分更新航向角
新航向角 = 原航向角 + 横摆角速度 * 仿真步长

坐标变换，更新全局位置
新全局 X 坐标 = 原全局 X 坐标 + (纵向速度 * cos (航向角) − 横向速度 * sin (航向角)) * 仿真步长
新全局 Y 坐标 = 原全局 Y 坐标 + (纵向速度 * sin (航向角) + 横向速度 * cos (航向角)) * 仿真步长

运动学模型

新横摆角速度 = 速度 * tan (前轮转角) / 轴距
新航向角 = 原航向角 + 横摆角速度 * 仿真步长
新全局 X 坐标 = 原全局 X 坐标 + 速度 * cos (航向角) * 仿真步长
新全局 Y 坐标 = 原全局 Y 坐标 速度 * sin (航向角) * 仿真步长
